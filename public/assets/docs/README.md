## 🔧 Como Gerar o PDF

### Opção 1: Via Navegador (Mais Simples)
1. Abra o arquivo `media-kit-magnafest-2025.html` no Chrome/Edge
2. Pressione `Cmd + P` (Mac) ou `Ctrl + P` (Windows)
3. Selecione "Salvar como PDF"
4. Salve como `media-kit-magnafest-2025.pdf`

### Opção 2: Via Linha de Comando (Requer Chrome)
```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --headless --disable-gpu --print-to-pdf="media-kit-magnafest-2025.pdf" media-kit-magnafest-2025.html

# Ou usando wkhtmltopdf (se instalado)
wkhtmltopdf media-kit-magnafest-2025.html media-kit-magnafest-2025.pdf
```
