# Portal MagnaFest v1.0

Portal web oficial do MagnaFest - O maior festival de música e cultura do país.

## 📋 Sobre o Projeto

O Portal MagnaFest é um site institucional desenvolvido para divulgar informações sobre o festival, incluindo:

- 🎵 Line-up completo dos artistas
- 🎫 Venda de ingressos
- 📍 Informações sobre o local do evento
- 📧 Formulário de contato

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📁 Estrutura do Projeto

```
portal-magnafest/
│
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos do site
├── js/
│   └── script.js       # Scripts JavaScript
└── README.md           # Documentação
```

## 💻 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/jmbento/portal-magnafest.git
```

2. Navegue até o diretório:
```bash
cd portal-magnafest
```

3. Abra o arquivo `index.html` no seu navegador ou use um servidor local:
```bash
# Usando Python 3
python -m http.server 8000

# Usando Node.js (http-server)
npx http-server

# Usando PHP
php -S localhost:8000
```

4. Acesse no navegador: `http://localhost:8000`

## 🎯 Funcionalidades

- **Navegação Suave**: Scroll suave entre seções
- **Design Responsivo**: Adaptado para desktop, tablet e mobile
- **Formulário de Contato**: Sistema de envio de mensagens
- **Animações**: Efeitos visuais ao scroll
- **Cards Interativos**: Informações sobre ingressos e line-up
